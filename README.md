# Mi Bot Web (plantilla mejorada)

Archivos:
- index.html
- styles.css
- script.js
- assets/LogoWeb.png
- assets/LogoWeb@2x.png (opcional, recomendado)
- assets/Fondoweb.jpg (recomiendo >=1920px ancho)

Pasos rápidos:
1. Coloca tus imágenes en la carpeta `assets` con estos nombres EXACTOS: `LogoWeb.png`, opcional `LogoWeb@2x.png`, y `Fondoweb.jpg`.
2. Abre la carpeta en Visual Studio Code.
3. Instala la extensión "Live Server" y abre `index.html` → haz clic en "Go Live".
4. Si ves imágenes rotas: abre DevTools (F12) → pestaña Network → filtra por Img → recarga y busca 404.
5. Para mejor nitidez en pantallas Retina, añade `LogoWeb@2x.png` (el doble de resolución).
6. Personaliza: cambia textos en index.html, colores en styles.css, o parámetros de partículas en script.js.

Despliegue:
- Subir al repo y usar GitHub Pages, Vercel o Netlify.
